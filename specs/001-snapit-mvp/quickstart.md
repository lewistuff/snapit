# Quickstart: snapit

## Build and run

```sh
make test     # unit tests (core) plus the render/flatten pixel test
make run      # release build → build/snapit.app (signed, see below) → open
make bench    # export/editor micro-benchmarks (release, src/bench.rs)
make measure  # bundle size, idle footprint, CPU, sockets
```

You need macOS 14 or later, Rust 1.88 or later (edition 2024, let-chains), and the Xcode Command Line Tools.

## First launch

1. snapit shows a camera icon in the menu bar, with no Dock icon.
2. An alert asks for **Screen Recording** access. Click **Open System Settings** and turn on snapit.
3. **Quit snapit from its menu and reopen it.** macOS only applies the permission after a relaunch.

## Using it

| Shortcut | Action |
|---|---|
| ⌘⇧C | Drag a region and it goes straight to the clipboard |
| ⌘⇧X | Drag a region and it opens in the editor |
| (unbound) | Capture a window, or capture a window and annotate. Set these in Preferences |
| Esc / right-click | Cancel the overlay |

**Editor**

| Shortcut | Action |
|---|---|
| V A R O L T N | Tools: select, arrow, rectangle, ellipse, line, text, step |
| ⌫ | Delete the selection |
| ⌘Z / ⇧⌘Z | Undo / redo |
| ⌘C | Copy and stay open |
| ⌘S | Save to the folder |
| 1–6 | Colors: red, yellow, green, blue, black, white |
| [ / ] | Smaller / larger (default: small) |
| ⌘↩ or **Done** | Copy and close |

- Double-click text with the select tool to edit it.
- In a text field, Enter commits and Esc cancels.

## Signing and rebuilding (research R4)

macOS ties the Screen Recording grant to the app's code signature. An ad-hoc signature changes on every build, which would mean granting access again after each rebuild. So `make app` runs `scripts/sign.sh`, which:

1. The first time, creates a self-signed `snapit-dev` code-signing certificate in its own keychain, `~/Library/Keychains/snapit-dev.keychain-db`. It is kept apart from the login keychain and needs no password prompt.
2. On every build, signs with that certificate. The signature macOS checks is "bundle id `dev.snapit.app` + this certificate", which stays the same across rebuilds, so the grant survives.

To sign with a real identity instead, run `make run SIGN_ID="Developer ID Application: …"`. If an old grant is stuck, run `tccutil reset ScreenCapture dev.snapit.app`. To start over with a fresh certificate, run `security delete-keychain ~/Library/Keychains/snapit-dev.keychain-db`.

The app icon is generated by `swift scripts/make-icon.swift`, which writes `assets/AppIcon.icns` and `assets/AppIcon.png`.

## Manual checkpoints

These need a person, because they involve the permission prompt, real hotkeys or mouse drags (see tasks.md):

- **T013**: ⌘⇧C, drag, then paste into Slack or Notes. Esc cancels. Focus returns to the previous app.
- **T016**: ⌘⇧X. Try every tool, undo/redo, move/delete/recolor, and step renumbering. Done → paste. ⌘S → file.
- **T020**: Rebind a shortcut. Change the folder. Toggle "also save" and launch at login. Pick a capture sound (it previews) and None (captures are silent).
- **T022**: Bind the window capture shortcut and capture a window that's partly covered by another.
- **T026**: Time hotkey → overlay (< 100 ms) and release → clipboard (< 300 ms). Check memory after closing the editor on a 5K capture.
